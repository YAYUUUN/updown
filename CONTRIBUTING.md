# Contributing

Issues and pull requests are welcome, in English or Spanish.

## Setup

```bash
python -m venv .venv && .venv/Scripts/activate      # Linux/macOS: source .venv/bin/activate
pip install -e ".[app,dev]"
```

## Before opening a pull request

```bash
ruff check .
python -m pytest -q
python -m updown audit
```

All three run in CI. Tests must stay offline: use synthetic data (`updown.audit.synthetic_bars`) or a fake
API session, never live downloads.

## Ground rules for new models and features

- **No look-ahead.** A feature or stage label for candle *t* may only use candles up to *t*. Add a test that
  changes the future and checks the past does not move (see `tests/test_updown.py`).
- **Count your trials.** A new model joins the multiple-testing correction; do not tune hyperparameters on
  out-of-sample results.
- **Report what you find,** including "no edge". Results files in `estudios/` are regenerated by their scripts,
  not edited by hand.

This is a research and educational tool. Contributions that turn it into automated trading or present its
probabilities as financial advice will not be merged.
