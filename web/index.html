Will the next candle close higher?

Barely. On 15-minute crypto candles the best models reach an out-of-sample AUC of 0.54 on the next candle, where 0.50 is a coin flip, and the edge fades to 0.51 by the fourth. On daily US stocks nothing beats "always up".

updown is an open-source Python tool that compares 13 models and a transformer on free market data and puts an honest track record next to every number. This page runs two of its models in your browser.

How it avoids fooling itself

  • Walk-forward with a purge. Every prediction comes from a model trained only on earlier data, with a gap so the last training target cannot peek into the test period.
  • Closed candles only. The last candle a feed returns is usually still moving; using it leaks the future.
  • Scored against “always up”. If prices rise 55% of the time, saying “up” every time is already 55% accurate, so accuracy alone proves nothing.
  • Corrected for many tries. With 13 models, one looks significant by luck almost half the time; p-values are Holm-corrected.
  • An audit in CI. On a random walk the verdict must be “no edge”, a planted signal must be found, and a leaked future value must make the AUC jump.
  • Settings fixed in advance. Tuning hyperparameters on the results would be more tries to correct for.

How this page works

  • Your browser downloads the last 1,000 candles of each market from Binance’s public API, drops the one still open and computes the same 28 features as the Python package.
  • Ridge and gradient boosting are exported from scikit-learn as plain numbers and trees, so the browser gets the same probabilities as Python. A test in CI checks that both agree.
  • The models are retrained every week on about two years of candles (…). The page has no analytics; its only outside requests go to Binance for the candles.
  • The latest-candles chart scores each candle with the model that was published at the time (this week's or last week's) and skips candles that model had already seen while training.
  • Market stage. A hidden Markov model learns from two years of candles a few states, each with its typical volatility (last day, against its past year) and 30-day trend, and how likely the market is to move between them. Each candle gets the probability of each stage given the candles up to it, never later ones; below 90% the stage is “uncertain”. Its past-year volatility reference is fixed at the weekly retrain, since the page does not download a year of candles.

Limitations

  • Statistically real is not economically useful: the edge is small next to trading costs.
  • Two years of crypto data cover a limited set of market conditions; the next regime may behave differently.
  • The latest-candles chart is recomputed in your browser, not a log written when each prediction was made, and a few days of candles say little: the long out-of-sample history is the track record.
  • The stage probability is the model's own belief, not a verified frequency: a hidden state has nothing to check it against. Because it reads slow-moving inputs it is often close to 100%, and a stage is only noticed once it has started.

Install and check
git clone https://github.com/YAYUUUN/updown && cd updown
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -e ".[app]"                              # add ,deep for the transformer
updown audit
Evaluate and explore
updown evaluate BTCUSDT,ETHUSDT --source binance --interval 15m --horizon 4
updown evaluate SPY --interval 1d
streamlit run app.py
